## 录制与剪辑要点

1. **先录 Block A 一遍**（脚本有 2.5s/节的停顿，`VIDEO_PAUSE` 环境变量可调：`VIDEO_PAUSE=3.5 python .../video_block_a.py`），口播失败就重录该镜，不必整条重来。
2. **Block B 的表格**建议先让脚本跑出结果，再切到对应文档页补讲，避免对着终端干念。
3. **数字一致性**：脚本全部读 `experiments/*/report.json`，与提交的 EFFECT_VERIFICATION_REPORT.md 同源，不会出现视频与报告数字打架。
4. **诚实红线**：本机无真麒麟运行时，Block A/B 的 backend 必须显示 `onnx(fallback: ...)` / `shim`，不得伪造 `kylin-sdk`；真机素材单独成段标注"麒麟真机环境"。
5. 总时长超 10 分钟可删 B3.3 / B4.2 / A7 备选；不够 8 分钟可加 A8（HTTP curl 演示）。
